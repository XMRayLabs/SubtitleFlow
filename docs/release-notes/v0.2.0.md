# SubtitleFlow v0.2.0

## 新增音频转录

主界面改为左侧导航，分「字幕处理」和「音频转录」两页，两页各自独立运行，互不影响。原有字幕处理功能和使用方式不变。

音频转录页支持拖入或选择音视频文件（mp3、wav、m4a、flac、aac、ogg、opus、wma、mp4、mov、mkv、avi、webm、m4v、flv、wmv），转录完成后 SRT 保存在源文件旁边，文件名与源文件一致。可一次加入多个文件，逐个处理，单个文件失败不影响其余文件。

- **分段转录**：长音频按设定时长分段，默认 5 分钟，可调 1–10 分钟。切点优先取目标位置前后 2 分钟内的静音处；附近没有静音时在目标位置强制切开，并在该行标注提醒，字幕可能在句子中间断开。显存较小或转录失败时可以调短分段。
- **从不覆盖已有字幕**：目标位置已有同名 SRT 时依次改存为「名称 (1).srt」「名称 (2).srt」，已校对过的字幕不会被覆盖。源文件目录不可写时，依次回退到用户目录下的输出文件夹。
- **随时取消**：取消在模型生成的下一步立即生效，不必等当前分段跑完；已完成的 SRT 保留，未开始的文件标为未处理。
- **失败重试**：重试只重跑未完成的文件，已完成的不会重复转录。完成后可直接打开结果所在文件夹。

## 转录服务

转录在独立的本机服务进程中完成，主程序不包含 torch 等重型依赖，因此应用体积和启动速度不受影响。服务只监听回环地址，所有请求都需要启动时随机生成的令牌。空闲一段时间后自动卸载模型释放显存，需要时再自动加载；服务意外退出时下次转录会自动重启。

首次使用需要在应用内安装转录服务（需下载数 GB，含模型）。安装支持断点续传，中断后再次安装从断点继续；下载内容逐文件校验哈希，校验不通过不写入。应用内可随时卸载。服务接口与主程序不兼容时，转录页会提示更新转录服务。

**音频转录目前仅支持装有 NVIDIA 显卡的 Windows。** 其他设备上转录页会说明原因，不提供安装入口，字幕处理功能不受影响。

## 构建与验证

Windows x64、Mac Apple Silicon、Mac Intel 三平台构建及独立启动验证通过，全部自动化测试（106 项）在三平台通过。包含已签名 update.json，现有客户端可检查更新。

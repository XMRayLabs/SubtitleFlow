# SubtitleFlow v0.2.1

## 字幕处理

- **译文编号**：勾选「翻译结果添加编号」后，翻译后的 SRT 每条正文开头加上顺序编号（如「12 译文」），便于按画面上的编号回查有问题的字幕。编号只写进翻译后的 SRT，导出的 FCPXML 标题不带编号。

## 音频转录

- **转录引擎选项**：转录页按转录服务实际提供的能力显示引擎、模型与语言；只有一个可选值的项不占界面。转录服务 1.0.0 不提供这些信息，此时不显示这一行，按默认设置转录。
- **更换转录服务后不再误用旧选项**：安装、卸载或更新转录服务期间读到的旧引擎列表会被丢弃，避免把旧服务的引擎名发给新服务导致整批转录失败。
- **连接失败的提示更具体**：区分转录服务已退出和响应超时，并放宽状态查询的等待时间，服务端短暂停顿不再让整个文件失败。

## 转录服务 1.0.1

- 修复部分 torch 版本上显存不足时报出难以理解的错误；现在统一提示「显存不足，请调短分段时长后重试」。
- 提供引擎、模型与语言信息，供 0.2.1 的转录页显示选项。

已安装转录服务 1.0.0 的用户可以继续使用，接口兼容，不会被要求重新下载。需要上述修复时，在应用内卸载转录服务后重新安装即可获得 1.0.1。
